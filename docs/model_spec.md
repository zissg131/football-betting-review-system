# 复盘模型说明 v0.1

## 这是什么

这是一个足球投注复盘评分模型，不是赛果预测模型。

它解决的问题是：

- 每一笔下注有没有赛前证据链；
- 是否存在冲动、追回、翻本；
- 仓位是否失控；
- 长期看哪些玩法、赔率区间、决策质量在赚钱或亏钱。

## 为什么不直接做预测模型

因为当前没有足够历史数据。

真正的预测模型至少需要：

1. 300-500 条以上真实投注记录；
2. 每条记录包含下注前理由，而不是赛后找理由；
3. 赔率、盘口、赛果、盈亏、本金、仓位；
4. 稳定回测；
5. 样本外验证。

没有这些，所谓预测模型只是包装过的主观感觉。

## 当前评分结构

单笔决策分满分 100，由四部分组成：

| 模块 | 权重 | 说明 |
|---|---:|---|
| 赛前理由质量 | 25% | 是否写清楚伤停、赛程、战意、盘口、赔率等因素 |
| 信息质量 | 25% | 0-5 手动评分，判断信息是否可靠 |
| 盘口逻辑 | 25% | 0-5 手动评分，判断盘口/赔率判断是否成立 |
| 仓位纪律 | 25% | 根据下注金额占本金比例和冲动标签自动扣分 |

## 等级规则

| 分数 | 等级 | 含义 |
|---:|---|---|
| 85-100 | A | 高质量决策 |
| 70-84 | B | 可接受决策 |
| 55-69 | C | 勉强合格 |
| 40-54 | D | 问题明显 |
| 0-39 | F | 垃圾决策 |

## 仓位纪律规则

仓位分初始为 5 分：

- 单笔仓位 > 1%：扣 1 分；
- 单笔仓位 > 2%：再扣 1 分；
- 单笔仓位 > 3%：再扣 1 分；
- 单笔仓位 > 5%：再扣 1 分；
- 出现“冲动、上头、追回、翻本”等标签：额外扣 2 分。

## 赛前理由评分规则

理由质量分初始为 0-1 分，根据以下因素加分：

- 是否有文字理由；
- 是否超过 20 字；
- 是否超过 50 字；
- 是否包含伤停、轮换、赛程、战意、盘口、赔率、阵容、体能等关键词；
- 是否包含多个关键因素。

## 关键指标

| 指标 | 含义 |
|---|---|
| ROI | 总盈亏 / 总投注额 |
| 命中率 | 赢的笔数 / 总笔数 |
| 平均赔率 | 所有投注赔率均值 |
| 最大单笔亏损 | 单笔最差结果 |
| 最大回撤 | 资金曲线从高点到低点的最大下降 |
| 冲动下注比例 | 带冲动、追回、翻本标签的笔数占比 |
| 平均决策分 | 所有单笔评分平均值 |

## 使用纪律

1. 每一笔都记录，不能只记录赢单；
2. 下注前写理由，不允许赛后补故事；
3. 单笔仓位尽量控制在本金 1%-2%；
4. 连黑后不允许加注追回；
5. 每 20 笔做一次小复盘；
6. 每 100 笔复盘玩法、赔率区间、联赛；
7. 300 笔以后再谈预测模型。

## 未来升级方向

v0.2 可以加入：

- 按玩法统计 ROI；
- 按联赛统计 ROI；
- 按赔率区间统计 ROI；
- 连续亏损预警；
- 自动生成复盘日报；
- 移动端更适配的录入界面。

v1.0 才考虑预测模型：

- 导入历史比赛数据；
- 导入赔率变化数据；
- 建立特征工程；
- 做回测；
- 做样本外验证；
- 输出概率而不是“必胜结论”。
